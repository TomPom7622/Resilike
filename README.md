# Resilike
My Unity game project. It's a survival horror game similar to Resident Evil 2 with fixed camera angles, inventory managment and simple resource draining combat. It's in a very early stage of developement.

# Controls
Up arrow -> go forward \n
Down arrow -> go backwards\n
Left arrow -> turn left\n
Right arrow -> turn right\n
E -> interact/confirm\n
Tab -> open inventory\n
N -> open notes\n
Backspace -> cancel\n
Shift -> run\n
Right mouse button -> aim\n
Left mouse button -> fire\n
