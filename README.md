# Resilike
My Unity game project. It's a survival horror game similar to Resident Evil 2 with fixed camera angles, inventory managment and simple resource draining combat. It's in a very early stage of developement.

# Controls
Up arrow -> go forward
Down arrow -> go backwards
Left arrow -> turn left
Right arrow -> turn right
E -> interact/confirm
Tab -> open inventory
N -> open notes
Backspace -> cancel
Shift -> run
Right mouse button -> aim
Left mouse button -> fire
